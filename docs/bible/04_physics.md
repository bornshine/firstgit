## 图钉（StaticBody2D，2026-09-27 物理化）

- 图钉为 **物理实体**（StaticBody2D），球撞钉由物理引擎原生解算反弹，**不可能穿钉**。
- **物理材质**：`PhysicsMaterial.bounce = 0.65`（钉子比球"硬一点但不钢"；与球的 0.8 按引擎规则合并，实际手感略偏弹）。
- **碰撞形状**：`CircleShape2D` r = 12。
- 手动反弹逻辑（`body_entered` + 速度改写）已整体移除（supersede 决策 #2）。

## 发射冲量（蓄力 + 鼠标瞄准）

| 参数 | 值 | 换算 |
| --- | --- | --- |
| `min_impulse` | 600.0 | 快速点击：Δv ≈ 600 px/s |
| `max_impulse` | 1600.0 | 蓄满 3s：Δv ≈ 1600 px/s |
| 蓄力曲线 | 线性 | `impulse = lerp(min, max, t / charge_time)` |
| 发射方向 | 鼠标瞄准 | `dir = (鼠标 − 发射器)`，钳制正上方 ±80° |
| 抖动 | ±5° | 仅按住 < 0.2s 的快速点击；蓄力 ≥ 0.2s 精准无抖动 |
| 球质量 | 1.0 | 冲量 = 速度变化 |

## 手感调优备注

- 球 `bounce` 0.8 与钉 `bounce` 0.65 由引擎合并（Godot 取 max 为主导），实际反弹接近 0.8；嫌弹可同时下调两者。
- 蓄力条 HUD：白色填充，蓄满变绿（暗示"完美蓄力"时机）。
- 低速贴钉的球可能慢慢滚落——正常物理行为，说明"阻碍"生效。

## 已知物理风险

| 风险 | 现象 | 缓解 |
| --- | --- | --- |
| 高速球穿薄检测条 | 下落 ~1300 px/s 单帧跨 22px，可越过 10px 袋洞条 | `Pocket` 自带 FallbackShape（640×30）兜底 |
| 球堆叠 | 多球同时落底重叠 | 球进入检测区立即销毁，实际不会堆积 |
| 图钉阵过密卡球 | 球在钉缝间反复微弹 | 行列间距可调（03_rules.md） |
