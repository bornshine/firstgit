## UI 层结构（已实现 + 规划）

| 层 | 内容 | 输入 |
| --- | --- | --- |
| 世界层 | 球 / 图钉 / 墙体 | 物理 |
| 游戏 HUD | 时间 / 库存 / 目标 / 蓄力条 | **不拦截**（Root/TopBar `mouse_filter = Ignore`） |
| 弹窗层 | 失败面板（结算/重试按钮） | 拦截（按钮默认 Stop） |
| 系统层 | 暂停 / 设置 | ❌ 规划 |

> ⚠️ 输入穿透是硬约束：全屏 Control 若保持默认 `mouse_filter = Stop`
> 会吞掉所有鼠标事件，导致发射失效（决策 #13）。新增全屏 UI 必须显式设 Ignore。

## 设计原则

1. HUD 不遮挡发射器（右下）和主要图钉区（上方）。
2. 数值变化必须有动效（数字滚动、颜色闪烁），否则玩家感知不到。
3. 回合结束界面必须显示"与上一回合的对比"，强化"再来一发"的动机。
4. HUD 文案为中文，未来若做多语言再抽离到本地化文件（P3）。
