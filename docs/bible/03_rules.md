# 03 规则（胜负判定、数值边界）

> **不变量**：所有可调数值集中在本文件 + `data/balance_config.json`，禁止散落在脚本硬编码。
> 修改任何数字时，请两处同步。
## 一局规则（已实现，数值见 data/balance_config.json）
	  - 起始库存球数：50；一局倒计时：90 秒；进入下一局阈值：库存 ≥ 60。
	  - 每次发射库存 -1（仅发射扣球）。
	  - 球落到普通底部区：不扣不加，球立即销毁。
	  - 球落到奖励袋洞：库存 +3（同帧多球 3×N 累加），球立即销毁。
	  - 库存 ≥ 60：PLAYING 期间随时触发——立即清场、HUD 闪"过关！"1.5s、库存重置 50 进入下一局（无按钮）。
	  - 倒计时归零 / 玩家点"结算"按钮 / 库存 = 0 且场上无球（含静止球）→ 结算：
		库存 ≥ 60 走过关通道；否则显示失败面板，等玩家点"重试"（库存重置 50）。
	  - 库存 = 0 时禁止发射；场上已有的球允许继续运动（中途进袋 +3 可恢复发射权）。
	  - 结算（SETTLING）瞬间锁定库存：场上余球继续被底部区销毁但不再计分。
	  - 进入下一局 / 重试均不继承库存（重置 50）。

## 胜负判定（已实现）

| 状态 | 条件 | 当前 |
| --- | --- | --- |
| 回合进行中（PLAYING） | 状态机初始态；倒计时走表，库存 > 0 可发射 | ✅ |
| 直接进入下一局（ENTERING_NEXT） | 库存 ≥ 60（随时触发） | ✅ |
| 结算 / 失败（SETTLING） | 倒计时归零 / 点结算 / 库存 0 且场上无球，且库存 < 60 | ✅ |
| 多局胜负 / 目标分 | 未做（MVP 边界外，见 ../MVP_Scope.md） | ❌ 不做 |

## 数值边界（当前实现值，来源：脚本 @export）

### 发射器（`launcher.gd`，蓄力 + 鼠标瞄准模型）

| 参数 | 当前值 | 边界建议 | 说明 |
| --- | --- | --- | --- |
| `charge_time` | 3.0 s | 1.0 ~ 5.0 | 蓄满所需时间（线性增长） |
| `min_impulse` | 600.0 | 200 ~ 1000 | 快速点击（未蓄力）冲量 |
| `max_impulse` | 1600.0 | 800 ~ 2500 | 蓄满冲量 |
| `angle_jitter_deg` | 5.0° | 0 ~ 15 | 快速点击时相对瞄准方向的随机偏移 |
| `jitter_free_threshold` | 0.2 s | 0.05 ~ 0.5 | 按住超过该时长后方向精准无抖动 |
| `aim_angle_limit_deg` | 80.0° | 30 ~ 90 | 以正上方为中心的最大射角（防朝地面发射） |
