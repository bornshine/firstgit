# Bible Index

> 每次开始新对话前，先读这个文件；
> 按任务匹配后只读对应的 1–2 个模块文件。

## 任何修改都不能违反（不变量）

1. 核心循环必须保留：瞄准 → 蓄力 → 发射 → 看球弹 → 球落底部 → 资源变化 → 想再来一发。
2. 所有可调数值必须集中：核心数字永远在 03_rules.md 和 data 目录的配置文件，禁止散落在脚本硬编码。
3. 音效调用统一走 AudioManager：禁止在游戏脚本里直接操作 AudioStreamPlayer。
4. 命名遵循 08_naming.md：AI 新增变量/节点/信号时必须先查命名约定，不得自造格式。

## 速查表：你要改什么，读哪个文件

| 你要改什么           | 读哪个文件                  | 一句话提示 |
| -------------------- | --------------------------- | ---------- |
| 加新实体（道具、敌人）| 02_entities.md, 08_naming.md | 必须先看命名约定 |
| 调数值（资源、参数）  | 03_rules.md                | 数字改动同步写入配置文件 |
| 调物理手感           | 04_physics.md              | 数值见 data/balance_config.json |
| 改 UI / HUD 显示     | 05_ui_hud.md               | 只讨论"显示什么"，不讨论坐标 |
| 改音效 / 加音效事件   | 06_audio.md                | 事件名改动同步 data/audio_config.json |
| 加新脚本 / 调目录     | 07_file_layout.md, 08_naming.md | 改完同步更新本索引 |
| 任何命名问题         | 08_naming.md               | 节点/变量/信号/枚举的命名规则 |
| 决定一件大事         | 99_decisions.md（追加）     | 格式：决策 #N / 日期 / 内容 / 理由 / 影响 |
