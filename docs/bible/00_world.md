# 00 世界观 / 主题 / 美术调性

> 白盒阶段也要写——它是后续所有美术资源的锚点。

## 一句话主题

一台会吐球的柏青哥机：玩家在钉子森林里赌下一颗球落袋。

## 世界观

- **载体**：一台虚拟柏青哥机（Pachinko），整台机器就是"游戏世界"。
- **玩家视角**：站在机台正前方，看到的是机台面板（钉子阵 + 收球袋 + 发射器）。
- **空间关系**：图钉阵在上半部、发射器在右下角、地面在最底部——这套关系不可随意改动。
- **氛围关键词**：霓虹、金属、赌博、机械、深夜柏青哥厅。
- **白盒阶段不做叙事**，只保证"面板 = 世界"的空间关系正确。

## 美术调性

| 维度 | 白盒阶段（当前） | 正式阶段（目标） |
| --- | --- | --- |
| 底色 | 纯黑 / 深灰（默认背景） | 深蓝黑 + 暗纹 |
| 图钉 | 白色柔边圆点（α=0.85），视觉半径 18 | 金属银钉 + 高光 |
| 球 | `icon.svg` 占位（scale 0.3） | 金属球 + 滚动高光 |
| 墙体 | 不可见（仅碰撞体） | 霓虹灯管边框 |
| 发射器 | 灰色半透明方块 | 机械发射槽 + 蓄力条 |
| 字体 | Godot 默认 | 复古点阵 / 日式风格标题 |

## 视觉参考

- **玩法**：Peggle / Peglin（弹珠 + 图钉阵）
- **氛围**：实体柏青哥机、日式霓虹街机厅
- **色彩**：深蓝底 + 青/洋红霓虹 + 金属银；正式阶段避免大面积纯白

## 白盒阶段的"允许不美"

- 图钉可以直接是白色圆点
- 球可以是 `icon.svg`
- 墙体可以完全不可见
- 但 **尺寸关系必须正确**：钉子阵在上、发射器在右下、地面在最下
