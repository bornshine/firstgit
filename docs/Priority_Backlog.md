## 优先级定义

- **P0**：不做这个就不是这个游戏——缺失会让游戏无法被识别为目标品类。
- **P1**：做了这个核心乐趣才完整——缺失会让核心循环跑得通但体验割裂。
- **P2**：做了能让游戏更耐玩——单局乐趣成立，但拉长游玩时间的关键。
- **P3**：做了能让游戏更"高级"——纯增量价值，删掉不影响核心循环。

## 功能优先级表

| 功能名 | 优先级 | 一句话理由 |
|---|---|---|
| 袋洞 / 收球器（球进袋则计分并停止） | **P0** | pachinko 的"目标感"全靠它，没有就只是球在乱弹 |
| 球数系统（每局限定 N 球，HUD 显示剩余） | **P0** | 没有"丢球压力"，玩家就不会紧张，蓄力→发射的循环也立不住 |
| 回合结束判定（球数 = 0 触发） | **P0** | 把"局"这个时间单位定义出来，"想再来一发"才有意义 |
| 重开机制（回合结束 → 下一局） | **P0** | 同一段流程不重开，玩家没机会验证升级、刷新运气 |
| 基础计分（袋洞分值 → 回合总分） | **P0** | 没有得分，整个回合就失去了"输了 vs 赢了"的判定基准 |
| 蓄力发射（按住越久力越大） | P1 | 让"发射"从"按一下"变成"决策一杆"，直接放大瞄准→蓄力→发射的快感 |
| 瞄准 / 方向控制 | P1 | 没有它，玩家就只是看 RNG 而不是自己玩，命中袋洞的成就感归零 |
| 分数 HUD（实时分数 + 剩余球数） | P1 | 没 HUD 玩家数不清自己赢没赢，反馈链路是残的 |
| 进球反馈（袋洞闪光 / 缩放 / 数字跳出） | P1 | 没有"命中那一刻的爽感"，核心循环就只剩操作没有奖励感 |
| 撞击反馈（图钉 / 墙的小粒子或抖动） | P1 | 球在场景里的每次碰撞都需要确认感，否则像在静音打砖 |
| 发射方向预览线（蓄力时显示轨迹） | P1 | 让"瞄准"从脑补变成眼可见，蓄力的意义才被玩家感受到 |
| 回合结束总分界面 | P1 | 没有结算画面，"再来一发的动力"就少了关键的回顾瞬间 |
| 难度递增（每回合球数 -1 / 袋洞缩小 / 图钉更密） | P2 | 让玩家感觉在"打越来越难的 Boss"，是耐玩性的核心来源 |
| 多种袋洞（分值 / 奖励差异化） | P2 | 单一袋洞分分钟腻，多袋洞让玩家做风险收益判断 |
| 升级选择（回合间三选一：发射力、球重、袋宽等） | P2 | "肉鸽"的灵魂，没它只是 pachinko；有了它才是 pachinko roguelike |
| 特殊图钉（+X 分 / 击退 / 复制球 / 暴击） | P2 | 给图钉阵增加变化，避免每次进图钉阵的反应完全一样 |
| 多球吐射（按住时概率多发一颗） | P2 | 让"蓄满力发射"有额外惊喜，放大风险/收益的赌博感 |
| 球种解锁（不同物理属性 / 视觉） | P2 | 增加"我想换这个球试试"的可玩目标 |
| 连击奖励（短时间内多次进袋累计加分） | P2 | 鼓励玩家连续精准瞄准，提高上限 |
| 元进度 / 永久升级 | P3 | 删了不影响玩法，但能让玩家持续有"成长感" |
| 成就系统 | P3 | 装饰性目标，不影响核心 |
| 存档 / 读档 | P3 | 体验加分项，不是循环必需 |
| 排行榜 / 在线分数 | P3 | 社交激励，单人完整可玩性已经成立 |
| BGM / SFX | P3 | 没声音也能玩，只是更"干" |
| 教程 / 新手引导关 | P3 | 玩家试两把就懂，缺它不阻塞核心 |
| 商店 / 货币系统 | P3 | 独立于肉鸽主循环的扩展层 |
| 粒子 / 屏幕震动 / 慢动作 | P3 | 纯氛围强化，剥掉不影响乐趣 |
| 主题切换 / 皮肤 | P3 | 纯美术变体 |
| Boss / 特殊关卡 | P3 | 单人原型阶段完全多余 |
