## 核心循环描述

玩家在限定球数内通过瞄准和蓄力发射小球，观看它在图钉阵中弹跳并试图落入袋洞得分；每进一袋保一球、得一奖，球数耗尽即回合结束、结算总分后玩家可选择重开，循环往复。

## 循环图

```
瞄准 → 蓄力 → 发射 → 看球弹 → 看进袋洞 → 看球数变化 → 想再来一发 → (回到瞄准)
```

## 动词 → 关键功能映射

| 动词 | 对应关键功能（优先级） |
|---|---|
| 瞄准 | 瞄准 / 方向控制（P1）、发射方向预览线（P1） |
| 蓄力 | 蓄力发射（P1） |
| 发射 | 发射器（已有基础）、蓄力发射（P1） |
| 看球弹 | 撞击反馈（P1）、物理反弹（已有基础） |
| 看进袋洞 | 袋洞 / 收球器（P0）、进球反馈（P1） |
| 看球数变化 | 球数系统（P0）、分数 HUD（P1） |
| 想再来一发 | 回合结束判定（P0）、回合结束总分界面（P1）、重开机制（P0） |
